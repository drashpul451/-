# DEFENSE — Завдання 2: Вимоги та Use Cases

### Намір і критерії (1–2 речення):
* **Намір** — Створити формалізовані вимоги EARS, сценарії використання Gherkin, Use Case діаграму PlantUML та M:N матрицю трасування для системи "Електронна Бібліотека" (`E-Library System`).
* **Критерії** — Тестовані EARS-вимоги; наявність ролей людей (`Guest`, `User`, `Librarian`) та 1 системного сервісу (`Notification Service <<System>>`); відсутність UML-антипатернів (вхід `Log In` описаний як Precondition); матриця M:N містить 19 зв'язків та 1 свідомо непокриту вимогу (`REQ-OUT-01`); повна узгодженість із 3NF ER-моделлю з Лаб №1 (`User`, `Author`, `Book`, `Loan`).

### Топ-3 розбіжності (spec ↔ артефакт) + коміт-виправлення:
• **Виправлення антипатерну `Log In <<include>>`**: Спочатку `Log In` було з'єднано зв'язком `<<include>>` з кожним прецедентом користувача. Виправлено: позначено як передумову сесії (Precondition) у специфікації та діаграмі (Коміт: `refactor(uc): set Log In as precondition instead of include`).
• **Позначення системного сервісу `<<System>>`**: Зовнішній сервіс відправки сповіщень про борги спочатку рендерився як актор-людина. Виправлено: додано стереотип `<<System>>` та винесено за межі рамки системи (Коміт: `fix(uc): add System stereotype for Notification Service`).
• **Консолідація M:N матриці трасування**: Первинна генерація розбивала таблиці. Зведено у єдину Markdown-таблицю $M:N$ із чітким підрахунком зв'язків та визначенням непокритої вимоги (Коміт: `docs(trace): consolidate M to N traceability matrix`).

### Ключове рішення — які альтернативи зважив і чому обрав цю (ADR):
Для збереження фонду книги та запобігання накопиченню боргів обрано правило блокування нових видач `Loan` у разі наявності прострочень (**ADR 0002**). Також винесено асинхронне нагадування про борги в окремий зовнішній сервіс `Notification Service <<System>>`, що відображено на Use Case діаграмі.

### Перевірка — узгодженість із попередньою моделлю (як перевірив):
Узгодженість перевірено зіставлянням `lab1/spec.md` та `lab2/spec.md`:
