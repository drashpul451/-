# User Stories та Gherkin Сценарії — Електронна Бібліотека

## US-01: Пошук книги у каталозі
* **Актор:** `Guest`
* **Вимоги EARS:** REQ-SYS-001, REQ-STA-001
* **Сутності:** `Book`, `Author`

```gherkin
Feature: Перегляд та пошук у каталозі
  As a Guest
  I want to шукати книги за назвою та авторами
  So that я можу знайти потрібну літературу без авторизації

  Scenario: Пошук книги за назвою
    Given я є неавторизованим відвідувачем на сторінці каталогу
    And у системі існує книга з title "Кобзар" та published_year 1840
    When я ввожу "Кобзар" у поле пошуку
    Then система повинна відобразити картку книги "Кобзар"
    And показати пов'язаного автора "Тарас Шевченко"

  Scenario: Спроба забронювати книгу без авторизації
    Given я відкрив деталі книги "Кобзар" як Guest
    When я натискаю кнопку "Забронювати"
    Then система повинна відхилити дію
    And перенаправити мене на форму авторизації
US-02: Бронювання книги читачем
Актор: User

Вимоги EARS: REQ-EVN-001, REQ-STA-002, REQ-UNW-001

Сутності: User, Book, Loan

Gherkin
Feature: Оформлення видачі книги (Loan)
  As a User
  I want to забронювати вільну книгу
  So that я можу взяти її для читання

  Scenario: Успішне бронювання книги
    Given я авторизований як користувач `User`
    And я не маю прострочених боргових книг
    And книга "1984" є вільною (відсутній активний `Loan`)
    When я надсилаю запит на бронювання книги "1984"
    Then система повинна створити запис `Loan`
    And встановити `borrowed_at` у поточний timestamp
    And розрахувати `due_date` через 14 днів

  Scenario: Відмова у бронюванні через наявність боргів
    Given я авторизований як користувач `User`
    And я маю прострочений запис `Loan`
    When я намагаюся забронювати книгу "1984"
    Then система повинна відхилити запит згідно з REQ-STA-002
    And показати повідомлення про необхідність повернути заборговану літературу
US-03: Управління поверненням книг бібліотекарем
Актор: Librarian

Вимоги EARS: REQ-EVN-002

Сутності: Loan, Book

Gherkin
Feature: Підтвердження повернення книги
  As a Librarian
  I want to позначати книги як повернуті
  So that вони знову ставали доступними для інших читачів

  Scenario: Успішне повернення книги
    Given я авторизований під роллю `Librarian`
    And існує активний `Loan` для книги "1984"
    When я фіксую повернення цієї книги
    Then система повинна заповнити поле `returned_at` поточним часом
    And книга "1984" стає вільною для наступних замовлень
